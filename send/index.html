  3. Project Settings → Script properties → add PASSCODE_GROOM, PASSCODE_BRIDE (and optionally PASSCODE for both sides).
  4. Deploy → New deployment → Web app → Execute as Me, access Anyone → Deploy.
  5. Put the Web app URL in wedding.json → guestSheet.url.
